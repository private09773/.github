# Hi, I'm John Adman 👋

**Free Software Foundation purist programmer. Not a larper.** 

I am the founder and architect of **Zanop Technologies**, an open-source collective dedicated to building a custom 64-bit operating system, a search engine, and a web browser entirely from scratch. We do not use modern web bloat. We do not use AI. We build from the ground up.

---

### 🛠️ The Zanop Ecosystem

*   **Zanop OS:** A custom 64-bit kernel. Not a Linux distro. Not UNIX. 
*   **ECMXS:** An English-based command shell (English Commands Mixed Set). No `ls`, no `sudo`. Just `con` and `cre dir`.
*   **ZSE:** The Zanop Search Engine, designed to filter out AI slop and modern web bloat.

### 🏛️ The Foundation

I am a strict adherent to the **Free Software Foundation (FSF)**. We use the **AGPL-3.0** license to ensure that corporations cannot take our code, modify it, and hide it behind a SaaS paywall. 

If you use AI to write your code, you are not a developer. You are a middleman for an LLM.
